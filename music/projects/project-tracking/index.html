01 / CONTEXT

为什么做这件事？

埋点方案要从 PRD 中拆出用户行为、事件、属性和指标口径，人工处理容易漏埋、重复定义事件，也很难复用历史资产。

怎样让埋点方案在研发前就可检查、可复用？
02 / APPROACH

设计与实现

01

理解需求

从 PRD 拆出业务目标、用户行为和事件属性。

02

复用与生成

03

校验与评审
